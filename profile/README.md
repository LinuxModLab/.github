# Linux Mod Lab

**Breaking compatibility barriers.**

*Built on Linux. Powered by open source.*

Welcome to **Linux Mod Lab**, an open-source initiative dedicated to exploring, developing, and documenting what's possible when Linux gaming, game modification, and community-driven development come together.

Our goal is to help push Linux gaming beyond conventional compatibility boundaries through practical experimentation, reproducible research, and collaborative problem-solving.

## What We Do

- **Compatibility Research** — Investigate how games, modding frameworks, plugins, and supporting tools behave on Linux.
- **Open-Source Development** — Explore and develop tools, modifications, and solutions that benefit the Linux gaming community.
- **Technical Documentation** — Publish findings, configurations, troubleshooting procedures, and verified results.
- **Cross-Distribution Testing** — Encourage testing across Linux distributions, hardware configurations, and compatibility environments.
- **Community Collaboration** — Bring together Linux enthusiasts, mod developers, testers, and contributors.

## Current Research

### GTA V Legacy / LSPDFR on Linux

Our initial research focuses on running advanced Grand Theft Auto V Legacy modifications under Linux, including:

- RAGE Plugin Hook (RPH)
- LSPDFR
- Proton and Wine compatibility
- Plugin loading and runtime behavior
- Audio and DirectSound compatibility

**Research is ongoing.** Experimental findings should not be mistaken for confirmed compatibility or fully working solutions.

While this is our starting point, Linux Mod Lab is not limited to GTA V or any particular game.

## Get Involved

Linux Mod Lab is being developed as an open, collaborative project. We welcome thoughtful contributions involving research, testing, documentation, software development, and technical discussion.

As the project grows, we'll establish contribution guidelines, compatibility reporting procedures, and opportunities for community participation.
